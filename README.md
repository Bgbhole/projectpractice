
# MechConnect – Vehicle Service Booking Platform

MechConnect is a full-stack web application designed to connect customers with nearby mechanics for vehicle servicing.  
The platform supports service booking, request tracking, and role-based access for customers and mechanics.

This repository acts as a **central hub** for the complete MechConnect project, including both backend and frontend codebases.

---

## 🚀 Project Overview

- Customers can register, log in, and book vehicle services
- Mechanics can manage service requests and update service status
- Secure authentication and role-based workflows
- RESTful backend with a modular, layered architecture

## ▶️ How to Run (High Level)

### Backend
1. Clone the backend repository
2. Configure MySQL database
3. Run the Spring Boot application

### Frontend
1. Clone the frontend repository
2. Open `index.html` in browser (or use Live Server)
3. Ensure backend APIs are running
